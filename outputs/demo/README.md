# Demo Artifacts

Thư mục này chứa các minh chứng (artifacts) cho kết quả chạy thuật toán A* và GA, phục vụ trực tiếp cho Báo cáo (Chương 5).

- `demo_summary.json`: Kết quả tổng hợp (baseline, optimized cost, generations, improvement).
- `convergence.json`: Lịch sử hội tụ của fitness qua từng thế hệ (dùng để vẽ biểu đồ line chart).
- `route_result.json`: Lộ trình và thứ tự điểm giao hàng tối ưu (dùng để vẽ đường đi thực tế trên bản đồ).
